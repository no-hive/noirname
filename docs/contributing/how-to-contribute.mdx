NoirName is an open-source protocol released under the **MIT License** — you are free to copy, modify, distribute, and build on it however you like. Pull requests are welcome. Before submitting a PR, check the open issues on GitHub to find where help is needed or to discuss a new idea.

## Contribution Guidelines

<Note>
  A `CONTRIBUTE.md` file with detailed contribution guidelines will be added to the repository soon. Review it before opening a pull request.
</Note>

Browse the **Issues** tab on the NoirName GitHub repository before starting any work. If you have an idea that isn't tracked yet, open a new issue to discuss it before writing code.
