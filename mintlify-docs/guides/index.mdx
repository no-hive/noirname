# Guides

## Contribute to NoirName

NoirName welcomes contributions to its Ethereum contract, Aztec contract, frontend, and documentation.

1. Browse [open issues](https://github.com/no-hive/noirname/issues) and choose one to work on.
2. If you have a new idea, open an issue first and describe the proposed change.
3. Fork the [repository](https://github.com/no-hive/noirname), make a focused change, and follow any setup or test instructions in the repository.
4. Open a pull request that explains the change and how you checked it. Link the related issue when there is one.

Check the repository's `LICENSE` and contribution instructions before submitting. The supplied project material describes an MIT license, but the repository's current files are authoritative.
