# About NoirName

NoirName is a prototype that connects ENS ownership on Ethereum with a private claim on Aztec. A user publicly proves ownership of an ENS name through an Ethereum transaction, waits for a message to reach Aztec, and claims a private record using a secret. Aztec applications can then use the claim for name-based checks without requiring every later action from the owner's public Ethereum wallet.

## Why it exists

An ENS name can serve as an identity in an application, but activity from its owner's Ethereum wallet is publicly traceable. NoirName explores how to use a name for membership, voting, donations, social features, or reputation in Aztec while reducing the need to reuse that public wallet for later actions.

## Where it can lead

NoirName is intended as a foundation for deeper projects built around identity on Aztec. A reusable link between an ENS name and a private claim could support richer identity systems, private donations, and coordination within DAOs. These are directions for future applications, not features delivered by the prototype.

## What a claim means

A claim shows that an ENS ownership check succeeded **at a particular time**. The record remains if the name is later transferred, expires, or ownership is otherwise lost; it does not by itself prove current ownership. Handling ENS name expiration is planned for after the MVP, with no fixed date yet. The original Ethereum transaction is public, and the privacy of later activity depends on the final contracts and how an application verifies and uses the claim. The verification interface is still being defined.
