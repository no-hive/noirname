# About NoirName

NoirName connects ENS ownership on Ethereum with private use of a name on Aztec. A user proves ownership through a public L1 transaction, then claims a private record on Aztec using a secret.

## Why it exists

ENS names are useful identities, but actions made directly from the owner's Ethereum wallet expose its public history. NoirName lets applications check a claimed name on Aztec without making every later action from that public wallet. This can support private membership, voting, donations, social features, and reputation.

The L1 ownership check is public. The design aims to keep later Aztec activity private; privacy depends on the final contracts and how applications use them.
